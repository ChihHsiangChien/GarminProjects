App Name

Poincaré HRV Visualizer

Short Description
Real-time visualization of RR-interval dynamics using a Poincaré plot for educational and exploratory purposes.

Full Description

Poincaré HRV Visualizer displays real-time RR-interval relationships using a classic Poincaré plot, commonly used in heart rate variability (HRV) research and signal analysis.

The app focuses on visualization, allowing users to observe short-term and long-term RR interval patterns directly on the watch during an activity.

Key Features

Real-time Poincaré plot based on consecutive RR intervals

Optional auto-scaling or fixed display ranges

Calculation and display of SD1, SD2, and SD1/SD2 ratio

Recent-beat trajectory visualization (tail effect)

Optional activity recording with SD1 and SD2 stored in FIT files

Intended Use

This app is designed for educational, research, and personal exploration purposes only.
It provides raw visualization and numerical descriptors of RR-interval dynamics without interpretation.

Important Notice

This app does not provide medical advice, diagnosis, or health assessment

The displayed values are not intended to indicate stress, recovery, fitness, or health status

Users should not make medical or training decisions based solely on this app

Activity Recording

When recording is enabled by the user, SD1 and SD2 values are written to the activity FIT file as custom fields. Recording starts and stops only through explicit user interaction.

Compatibility

Requires a Garmin device capable of heart rate measurement

Accuracy depends on sensor quality and signal conditions

Privacy Statement

This app processes heart rate and RR-interval data locally on the device only.
No data is transmitted, stored externally, or shared with third parties.
